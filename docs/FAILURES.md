# Failures and fixes

This is a running, factual engineering log. Add entries only for problems actually encountered during development, including their observed impact, diagnosis, fix, and regression protection.

| Date | Symptom | Root cause | Fix | Regression protection |
| --- | --- | --- | --- | --- |
| 2026-08-25 | `./mvnw test` failed before the context test because Mockito could not self-attach a Byte Buddy agent. | The test runtime selected Mockito's inline mock maker, which requires JVM agent attachment unavailable in the local environment. | Configured Mockito's subclass mock maker for test scope. No current tests require inline mocking. | Full Maven test suite runs without JVM self-attachment. |
| 2026-08-29 | Thymeleaf TemplateInputException during MockMvc rendering of dashboard.html. | String concatenation in `th:onclick` violated standard Thymeleaf DOM event attribute processor security constraints. | Switched from `th:onclick` expression concatenation to `th:attr="data-payment-id=..."` with native `onclick` reader. | DashboardControllerTest parses and renders full Thymeleaf DOM during `./mvnw test`. |
| 2026-09-05 | App boots and works but 0 Gemini calls appear in the UI (all fallback). Logs show continuous HTTP 429. | The orchestrator submitted ~35 Gemini calls concurrently at boot, which instantly triggered the Free Tier burst limit (15 requests/minute). | Added a strict client-side rate limiter in `GeminiClient` that caps requests to 3 per batch and added a quota reset hook for each new batch run. | End-to-end tests cover fallback behavior. Local manual tests verify that the first 3 calls succeed and remainder degrade gracefully without thread starvation. |
| 2026-09-05 | Gemini classification still failing after adding rate limiter, getting continuous HTTP 429. | The `gemini-3.6-flash` free tier has a hard daily cap of 20 requests per project, which was exhausted during testing. | Switched the model string to `gemini-3.5-flash-lite`, which maintains a separate free tier quota and still yields highly accurate JSON classifications. | The client-side rate limiter ensures we don't accidentally burn through the new quota instantly. |
| 2026-09-05 | Setting API key in terminal via `export` was not being picked up by `./mvnw spring-boot:run`. | Running the `export` command in one terminal tab and the Maven daemon in another meant the JVM never received the environment variable. | Moved the `GEMINI_API_KEY` configuration directly into `src/main/resources/application.properties` and added the file to `.gitignore`. | Application boots reliably regardless of the host shell environment. `SecretValidator` catches missing keys on boot. |
